# DiscoSdk documentation

This folder holds DiscoSdk's product and technical documentation. It replaces the old hand-maintained
`feature-coverage.html` as the **source of truth for what the SDK implements**.

- **PRDs** (`prd/`) describe *what* and *why*. In the Discord API series, section 6 of each PRD lists
  every capability Discord offers bots for that area, with an implementation status and the SDK evidence.
- **SPECs** (`specs/`) describe *how*: models, components, flows, concurrency, errors, tests and history.
- **`tools/coverage.py`** checks the PRD tables against the official Discord docs (pinned in
  `tools/baseline.json`) and against `Src/`. It fails when a Discord capability is unmapped, when a
  status is wrong, or when cited evidence does not exist. See [`tools/README.md`](tools/README.md).

## Conventions

| Topic | Rule |
|---|---|
| Series | **API series** — `PRD-API-NNN`, files `prd/api-NNN-<slug>.md`: one PRD per Discord docs page (or small group of pages), mapping every capability Discord offers bots in that area. **SDK series** — `PRD-SDK-NN`, files `prd/sdk-NN-<slug>.md`: DiscoSdk's own framework features, which are not Discord endpoints (bootstrap, dispatch, command framework, caching, observability). A PRD and its SPEC share the ID number and slug (`specs/api-NNN-<slug>.md`, `specs/sdk-NN-<slug>.md`). |
| Requirement IDs | `<PREFIX>-F<nn>` for capabilities and functional requirements, `<PREFIX>-N<nn>` for non-functional ones. The prefix is unique per PRD (see the index). SPEC §11 maps tests to these IDs. |
| Row status | **Implemented**: usable from the public API. **Partial**: reachable but incomplete (missing parameters, fields or behaviour, described in the row). **Missing**: not available. **Excluded**: deliberately out of scope, with the reason. **Deprecated**: Discord deprecated or removed it. |
| Document status | Draft → In review → Approved → Implemented → Obsolete. |
| Evidence | Public entry point first, then the internal implementation after `→`, e.g. `IGuild.Bans.Ban()` → `GuildClient.BanMemberAsync`. |
| Language | Documents are in English; identifiers are verbatim from the code and the Discord docs. |
| Templates | [`prd/_template.md`](prd/_template.md), [`specs/_template.md`](specs/_template.md). |

## Discord pages out of scope

Every page in the Discord docs navigation's *Reference* tab, plus the *Interactions* and *Components*
groups and the Teams topic, must be owned by a PRD or listed here. `coverage.py check` enforces this.
Guides, tutorials, Activities and Social SDK client pages are narrative and out of scope by rule.
